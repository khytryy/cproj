# cproj - Project/package manager for C
cproj is an open source project/package manager for C designed to make it easy to create a project or add libraries to one.

> [!CAUTION]
> This project is still in development, so expect a lot of unfinished stuff.

## Installing
To install cproj, you will need go. After installing go, run:
```bash
go install github.com/khytryy/cproj@main
```

This will install cproj onto your machine and add it to PATH automatically.
